特斯拉访问地址

车机连接这台安卓设备的热点时，可在安卓「特斯拉访问地址」中授权 Root 并启用 100.96.0.1。此功能不提供互联网，不改变热点网段，也不占用 VPN。

需要先在安卓设备上启用 Root 访问。由本机回应车机联网检查；这不会提供互联网，车机自带音乐和在线地图仍需要外网。

HTTPS 画面的域名与证书

仅用于通过自己的域名以 https:// 打开 CarPlay 画面。使用 http:// 画面或管理页时，无需配置此项。

域名需解析到本机，证书需被车机信任。可导入 PEM 格式的证书链和未加密私钥；导入不会自动修改 DNS。

切换会重启接收服务，CarPlay 会短暂断开。停用会保留证书材料。域名或 HTTPS 页面打不开时，请使用上面的 http:// 管理地址修改设置，无需证书。

自动申请与续期

为本设备使用独立域名。联网时自动维护 IPv4 解析和证书；没有 SIM 卡时，也可经外部 Wi-Fi 或以太网上网。离线时保留已有证书。

token 只保存在设备上，不会回传。DuckDNS 名称须供本设备独用，不能与其他程序共用 TXT 验证记录；deSEC token 需有修改本域名 A 与 TXT 的权限。

查看证书服务条款

签发后的域名会出现在公开证书记录中。本功能不清除已有 IPv6 解析；请勿为此域名配置指向其他设备的 AAAA 记录。

接收服务运行时才会自动维护。新证书在 CarPlay 空闲时加载。关闭自动维护会保留当前证书；手动导入或切换证书会同时停止自动维护。未完成的验证记录将在联网后清理。

安卓盒子的有线 CarPlay 需在本机「数据线连接」页面启用，允许 USB 与本地 VPN，并在 iPhone 上选择信任。浏览器无法代为确认系统授权。

建议使用 5 GHz Wi-Fi，以获得更好的画面流畅度；这里指 Wi-Fi 频段，不是手机的 5G 移动网络。

使用 iPhone 网络

首次需在安卓设备的 USB 设置页（手机为「USB 上网」，盒子为「数据线连接」）启用并允许使用 iPhone 网络，且 iPhone 已开启个人热点。此选项让安卓应用经 iPhone 使用 IPv4 互联网，可能消耗 iPhone 流量。个人热点暂不可用时暂停外网，CarPlay 和局域网仍可使用；拔线或关闭此项后恢复系统原有网络。给热点设备共享网络需另行开启下方 Root 选项。

首次需在安卓设备的 USB 设置页（手机为「USB 上网」，盒子为「数据线连接」）允许 Root 共享。车机需连接这台设备的热点；共享期间不转发热点设备的 IPv6 互联网，不改热点网段与 DHCP。关闭后恢复原有转发规则。系统热点需已支持转发，也可使用本应用创建的热点。

网页访问

默认端口为 18743。更改后请使用新地址，原地址将停止服务。

HTTP 免 Root 兼容入口（实验性功能）

HTTP 页面优先使用 WebRTC 视频，连接失败时自动改用 JPEG 图片。JPEG 的最大边不超过 1280 像素，实际清晰度和流畅度受设备性能影响；WebRTC 的实际效果取决于设备、浏览器和网络。请在车机上检查画面和触控。管理页始终通过 HTTP 提供设置、身份导入、证书和更新功能，关闭此画面开关不会关闭管理页。HTTP 和 HTTPS 使用上方同一个端口；更改后接收服务会重启。

启动与连接释放

默认 300 秒；填 0 则持续连接。重新打开画面后会再次邀请 iPhone。

为连接本机热点的设备提供域名解析，使车机在无互联网时仍能通过域名访问接收端。如果影响车机自带应用联网，可关闭此项。需在设备上开启特斯拉联网检查、USB 热点共享或在「自己的网址与证书」页授权 Root 接管 53 端口。

部分系统还需在应用管理中允许自启动与后台运行。

需先导入身份。安卓手机仅支持无线，需要 Wi-Fi 参数与蓝牙配对；安卓盒子的有线连接还需在本机启用并完成系统授权。

保存后接收服务会重启，页面可能短暂断开。

这台设备能做什么

无 Root 可运行无线接收和网页服务，使用系统已开的热点或外部局域网。Root 能提供地址与路由配置权限，但不能让不支持热点的网卡获得热点能力。

VPN 创建本机虚拟网卡，并不等于车机能通过热点访问这个地址；特斯拉和 USB 网络都需要验证实际链路。
